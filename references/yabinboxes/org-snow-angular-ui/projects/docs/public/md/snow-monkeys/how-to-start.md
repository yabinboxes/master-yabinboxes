# <a id="how-to-start"></a>How to Start

## <a id="available-installation-options"></a>Available Installation Options

1. **Local Installation**

Offers full functionality using your own hardware.

2. **Web Dashboard**
You can start using it immediately, although with some limitations.


### <a id="web-version-limitations"></a>Web Version Limitations

**Self License:**

- Only 1 deployed application.
- Maximum 20 resources on the dashboard.

**Individual License:**
- Up to 20 simultaneously deployed applications.
- Unlimited resources on the dashboard.
- Data persistence available both locally and on the web.

## <a id="publish-a-resource-on-the-dashboard"></a>Publish a Resource on the Dashboard
Once you have an active account and an installation (local or web), repositories can be automatically detected or added manually via the API from your development pipeline.


## <a id="reporting"></a>Reporting
You can extend the dashboard's functionality by using and consuming the **reporting** module.
