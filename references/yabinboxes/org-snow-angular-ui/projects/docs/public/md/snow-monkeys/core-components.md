## <a id="core-components"></a>Core Components

### <a id="services"></a>Services
Shared resources linked to one or more applications. For example, a file storage bucket used by multiple applications.

### <a id="cluster"></a>Cluster
Infrastructure environment that hosts services or applications. This can be a cloud platform, a physical cluster, or a virtual machine, and it defines the configuration and location of the deployment.

### <a id="application"></a>Application
Software developed in a specific programming language (such as JavaScript, Python, etc.), designed to run within a cluster and use the associated services.
