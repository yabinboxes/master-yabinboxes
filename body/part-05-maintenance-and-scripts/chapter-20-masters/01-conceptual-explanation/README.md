# 1. Conceptual explanation

Chapter 3 names five masters. A master file states the rule. The other repositories in the same parent directory are the implementation of that rule.

| Chapter 3 master | Rule files | Implementation |
| --- | --- | --- |
| master-modules | [snow-monkeys-modules/master-modules](../../../../../../snow-monkeys-modules/master-modules/main.md) | [snow-monkeys-modules](../../../../../../snow-monkeys-modules) |
| master-infra | [snow-monkeys-infra/master-infra](../../../../../../snow-monkeys-infra/master-infra/main.md) | [snow-monkeys-infra](../../../../../../snow-monkeys-infra) |
| master-test | [test-snow-monkeys/master-test](../../../../../../test-snow-monkeys/master-test/main.md) | [test-snow-monkeys](../../../../../../test-snow-monkeys) |
| org-master | [yabinboxes/org-master](../../../../../org-master/main.md) | [yabinboxes](../../../../../) |
| master-yabinboxes | [yabinboxes/master-yabinboxes](../../../../main.md) | [yabinboxes](../../../../../) |

`org-master` and `master-yabinboxes` both live under `yabinboxes`. `org-master` is the service list. `master-yabinboxes` is this book, and Chapter 3 says the book includes every repository in `yabinboxes`.
